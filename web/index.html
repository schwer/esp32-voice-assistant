Install or update

Plug the board in with a USB-C data cable, then click Install. The newest firmware installs automatically. Your Wi-Fi and settings are kept.

Don't see the board in the list? Hold BOOT, press RESET, release BOOT, then click Install again.

Get a Gemini API key

The assistant uses your own key with Google's Gemini Live API. You pay Google directly. Nothing goes through us.

  1. Go to Google AI Studio → API keys and sign in.
  2. Click Create API key. If asked, let it create a new Google Cloud project.
  3. Copy the key. It starts with AIza.
  4. Open the board's setup page (shown above after installing) and paste the key there.

Free or paid? The free tier is fine for trying it out, but it's rate-limited and Google may use free-tier conversations to improve its products. For everyday use, turn on billing for the key's project in AI Studio. Short chats typically cost a cent or two. See Gemini API pricing.

Treat the key like a password. Only enter it on your own board's setup page. If it leaks, delete it in AI Studio and create a new one.
