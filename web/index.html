ESP32 Voice Assistant

Firmware __VERSION__ for the Waveshare ESP32-S3-AUDIO-Board

Your browser can't flash devices. Use desktop Chrome or Edge. Flashing needs a secure (https) page.
How to install
  1. Connect the board to your computer with a USB-C data cable.
  2. Click Connect and pick the board's serial port.
  3. Choose Install. The first install erases the device.
  4. When prompted, enter your Wi-Fi network (2.4 GHz).
  5. Open the device's setup page to enter your Gemini API key and time zone.

If the port doesn't appear, hold BOOT, press RESET, then release BOOT and try again.

Open source: github.com/schwer/esp32-voice-assistant. Not affiliated with Google.
